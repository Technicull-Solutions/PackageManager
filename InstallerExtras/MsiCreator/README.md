# Legacy MSI wrapper

This inherited Visual Studio setup project is not part of the maintained Evergreen release pipeline and is not validated for current NativeAOT packages.

Use the Windows x64 `.Setup.exe` or application ZIP from [Evergreen releases](https://github.com/Technicull-Solutions/PackageManager/releases). Maintainers should follow [the contributor workflow](../../docs/EVERGREEN_CONTRIBUTOR_WORKFLOW.md) and use `scripts/build.ps1` for the supported Inno Setup packaging path.
