# Evergreen security policy

Report Evergreen Endpoint Package Manager issues to the maintainers of [Technicull-Solutions/PackageManager](https://github.com/Technicull-Solutions/PackageManager).

Private vulnerability reporting is not currently configured. Do not publish vulnerability details, exploit code, credentials, or identifying logs in a public issue. Open a minimal issue requesting a private contact method without including sensitive details, then wait for the maintainers to arrange an appropriate channel.

This fork does not use Devolutions' security intake or crash-report service. Upstream vulnerabilities should be reported to the affected upstream project through its own policy.
